# Trend Chart Contract (2026-04-12)

Scope: `new_strategy/streamlit_app.py` → `render_global_trends()`의 **Top 키워드 점수 추이(최근 30일)** 차트

## Rendering Contract
1. 기본 표시 키워드 수는 `10`이다.
2. 표시 대상 키워드는 `기준일(latest)`의 Top N으로 고정한다.
3. x축은 최근 30일을 `MM-DD` 라벨로 모두 표시하고, 라벨은 90도 회전한다.
4. 키워드별 시계열은 날짜 기준으로 정렬된 **연속 시계열**로 렌더한다.
5. 선 종류는 반드시 2개만 사용한다.
   - `TopN 내`: 굵은 실선
   - `TopN 밖`: 점선
6. 실선/점선은 구간 필터로 분리되며, 동일 구간에 중복으로 겹치지 않는다.
7. 연속성 보조선(제3선), 포커스 키워드 강제 단일표시, 임의 숨김 레이어는 기본 모드에서 사용하지 않는다.

## UX Contract
1. 차트 상단 컨트롤은 한 줄 구성 유지:
   - `추이 표시 키워드 수` + 기간 요약 메타
2. 범례 클릭으로 강조는 허용하되, 기본 출력은 Top N 전체를 동시에 보여야 한다.

## Change Policy
- 위 계약 변경 시에는 이 문서를 먼저 갱신하고, 그 다음 코드 반영한다.
- 계약 위반 버그 발생 시 우선순위는:
  1) 선 종류(2개) 준수
  2) 연속성 유지
  3) 기준일 Top N 정합성
