# V2 Dashboard Migration

## 목적

- V1 점수형 전략 흔적을 사용자 화면에서 제거한다.
- V2 기본안인 `월봉매수 / 주봉매도 / buy_0%__sell_-5%`를 기준 전략으로 고정한다.
- 대시보드를 `의사결정 / 전종목 분석 / 보유/검증 / 연구실` 4분할 구조로 재편한다.

## 제거한 V1 흔적

- `의사결정` 화면의 `확신점수`, `표시점수`, `최적MA 가점` 표시 제거
- `HOLD -> SELL_WATCH` 전환에서 점수 기준 제거
  - 이제 `weekly_sell_watch` 리스크 플래그 중심으로만 경계 전환
- 텔레그램 응답의 `점수`, `평균 전략 점수`, `표시점수` 표현 제거
- 메인 사이드바 페이지 구조에서 구 V1 운영 흐름 제거
  - `전략 보고서 / 데이터 상태 / 백테스트 / 사후검증 / 전략 설정 / 접속 안내`
  - 위 구조를 기본 화면에서 더 이상 사용하지 않음

## V2 기준 치환 내용

### 1. 메인 전략 표현

- 기본 전략: `월봉매수 / 주봉매도 / buy_0%__sell_-5%`
- 메인 판단축: `최적 MA`
- 보조축: `주가위치`, `매크로`, `재무`

### 2. 의사결정 규칙 표현

- `WATCH`는 `BUY_WATCH` 계열로 해석
- `HOLD`는 기본적으로 `보유유지`
- `weekly_sell_watch`가 붙은 `HOLD`만 `SELL_WATCH`로 승격
- 매크로 리스크만으로 `SELL_WATCH`를 만들지 않음

### 3. 매크로 표현

- 화면 표기는 `정상구간 / 주의구간 / 방어구간`
- `exposure`는 `운용강도`로 해석
- 매크로는 종목 방향을 뒤집는 축이 아니라 운용 강도 조절 축으로 사용
