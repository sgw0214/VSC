# Briefing Update Policy

Updated: 2026-03-27

- 회사정보 / 컨센서스: `07:00 / 1회`
- 최근 기사: `07:00-22:00 / 1시간`
- 일반 공시: `07:00 / 1회`
- 재무 공시: `파이프라인 완료 후 반영`

Notes

- The dashboard uses the same policy values for display labels and external-fetch cache keys.
- Company info / consensus and general disclosures refresh once per day after `07:00` Asia/Seoul.
- News refreshes hourly during the `07:00-22:00` window and keeps the latest active slot outside that window.
- Financial disclosures depend on the local pipeline output file refresh.
