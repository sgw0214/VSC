Hackathon One-Page Summary

PLC 접점 기반 장비 이벤트 데이터로 제조 데이터 품질 혁신

현재 제조 데이터는 패널 결과나 In~Out 통계량 중심이라 장비 내부의 실제 동작을 충분히 설명하지 못합니다. 해법은 장비가 동작할 때마다 발생하는 PLC 접점 신호를 이벤트 데이터로 표준화해, 공정을 결과 중심 데이터에서 행위 중심 데이터로 전환하는 것입니다.

패널 기준 데이터 → 장비 기준 이벤트 데이터

왜 필요한가

SPC는 패널 배출 시점의 결과를, FDC는 패널 In~Out 구간의 통계값을 보여줍니다. 하지만 장비 안에서는 이송, 정렬, 클램프, 진공 형성, 공정 시작/종료, 알람 발생 같은 세부 이벤트가 연속적으로 일어납니다. 이 정보가 빠지면 데이터와 실제 공정 간 정합성이 낮아지고, 원인 분석과 AI 적용에 한계가 생깁니다.

현재 한계: 실제 작업 순서와 상태 전이를 데이터로 보기 어렵다
핵심 아이디어: PLC 접점을 기준으로 이벤트 단위 데이터를 생성한다
관점 전환: 패널이 무엇이었는지뿐 아니라 장비가 무엇을 했는지 본다
지금

결과와 통계는 있지만, 공정 내부 흐름은 불명확합니다.

제안 후

장비 동작 시점이 보이므로 이상 구간 추적력과 설명력이 올라갑니다.

기대 효과

정합성 향상

실제 장비 동작을 기준으로 데이터를 만들기 때문에 공정과 데이터의 불일치를 줄일 수 있습니다.

원인 분석 강화

불량과 이상 발생 시 어느 이벤트 구간에서 문제가 시작됐는지 더 정확히 볼 수 있습니다.

Vertical AI 준비

공정 특화 AI에 필요한 세분화된 고품질 학습 데이터 기반을 확보할 수 있습니다.

End-to-End 확장

결과 예측을 넘어 공정 흐름 전체를 연결해 최적화하는 구조로 발전할 수 있습니다.

해커톤 PoC 범위

01 대상 선정

특정 공정 또는 대표 장비 1대를 선정합니다.

02 이벤트 표준화

PLC 접점을 추출해 이벤트 테이블로 정의합니다.

03 기존 데이터 연계

SPC, FDC와 시간축 기준으로 매핑합니다.

04 효과 검증

실제 이상 사례 1~2건으로 기존 대비 개선 효과를 보여줍니다.

결과 데이터만 보는 제조에서, 장비 행위 데이터까지 보는 제조로 전환하겠습니다.

이 제안은 데이터 수집 항목을 조금 늘리는 수준이 아니라, 제조 데이터를 AI 친화적인 구조로 재설계하는 시작점입니다.
