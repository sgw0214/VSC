To Do List 배포용 파일

구성
- ToDoList.exe : 실행 파일

실행 방법
1. ToDoList.exe를 실행합니다.
2. 처음 실행하면 빈 상태로 시작합니다.
3. 데이터는 각 사용자 PC의 다음 경로에 저장됩니다.
   %LOCALAPPDATA%\ToDoList\tasks.json

알림 등록
1. 상단에서 원하는 시간을 선택합니다.
2. 등록 버튼을 누르면 Windows 작업 스케줄러에 매일 실행으로 등록됩니다.
3. PC가 켜져 있어야 알림이 동작합니다.

주의
- 설치파일은 필요 없습니다. exe만 실행하면 됩니다.
- 사용자별 데이터는 각자 PC에 따로 저장됩니다.
- 사내 보안 정책에 따라 처음 실행 시 Windows 경고가 보일 수 있습니다.
